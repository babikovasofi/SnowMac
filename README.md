# SnowMac

## Локальный прототип

Откройте `SnowMac.xcodeproj` в Xcode, выберите схему SnowMac и нажмите Run.
Приложение появится под значком снежинки в строке меню. Ползунок меняет
интенсивность осадков, замок переключает взаимодействие с рабочим столом.

Проверки прототипа для разработчиков:

```sh
xcodebuild test -project SnowMac.xcodeproj -scheme SnowMac -destination 'platform=macOS'
```

В SnowMac установлен Harness для Codex. Источник переноса — [babikovasofi/harness@1957392](https://github.com/babikovasofi/harness/tree/1957392).

## Работа в Codex

Откройте новую сессию в корне SnowMac. Codex читает [AGENTS.md](AGENTS.md) и
находит скиллы в `.agents/skills/`. Можно написать обычную задачу или указать
скилл, например `$day`, `$debug` или `$review`.

- **День.** Уточнение при необходимости, план, согласование, реализация,
  проверка. В форме выбора у вариантов есть плюсы и минусы. Если в клиенте
  нет формы, варианты появятся в чате.
- **Ночь.** `$night` согласует бриф, затем работает в отдельном git worktree.
  `$night-stop` завершает работу и собирает отчёт. Публикацию отдельного
  PR для Memory Bank можно включить в бриф.
- **Контекст.** [.memory-bank/index.md](.memory-bank/index.md) хранит
  сведения о проекте. Планы и отчёты сохраняются в `swarm-report/`.
- **Исследование.** `$research` использует веб-поиск. Глубокий режим
  включается явной просьбой и использует Tavily.
- **Остальные скиллы.** Мутационные тесты, новый агент, Steward и дефрагментация
  Memory Bank, транскрибация, редактура и перенос Harness в другой проект.
  Полный список и правила находятся в [AGENTS.md](AGENTS.md).

## Хуки и локальные инструменты

Просмотрите и разрешите хуки в клиенте Codex. В CLI используйте `/hooks`.
В приложении откройте Review hooks в поле ввода или Settings → Hooks.
Хуки используют Bash, Python 3, Git, jq и Perl. При наличии ast-index
SessionStart обновляет индекс в фоне. Настройки тестов и линта находятся
в [.codex/harness/quality.json](.codex/harness/quality.json).
Сбор конкретных доказательств тестирования остаётся частью build и review.

Для Tavily предпочтителен подключённый плагин. Для локального MCP добавьте
ключ по образцу [.env.example](.env.example), включите сервер в
[.codex/config.toml](.codex/config.toml) и откройте новую сессию из корня
проекта. Локальный сервер использует Node.js и npx. Транскрибация использует
локальные зависимости, указанные в
[инструкции транскрибации](.agents/skills/transcribe/references/local-setup.md).
