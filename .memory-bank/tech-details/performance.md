# Визуальное качество и нагрузка

Для первой версии важны плавное осыпание снега при движении окна, отзывчивое перетаскивание предметов и детализированные иллюстрации. При длительной фоновой работе SnowMac должен экономно расходовать заряд и память, избегать устойчивой тепловой нагрузки. Дистрибутив с пятью парами обоев должен быть компактным.

## Проверка прототипа

Доступная машина заказчика — MacBook Air M5 с накопителем 1 ТБ. Замеры запланированы на этап прототипа. Повторить их на более ранней и менее мощной модели из поддерживаемого диапазона. На каждой машине отдельно при одинаковых яркости, питании и рабочей нагрузке сравнить работу без SnowMac, фоновый снег под замком и метель с игрой. Дать каждому режиму прогреться. Записать время кадра и пропуски при движении окна, CPU/GPU, энергопотребление, тепловое состояние macOS и пик памяти при смене всех сцен. Проверить остановку отрисовки при сне дисплея. Для релизной сборки измерить размер скачиваемого DMG и приложения после установки.

## Что попробовать

Загружать полноразмерную иллюстрацию для текущей сцены, в меню использовать миниатюры. Сравнить варианты сжатия по полосам в градиентах неба и деталям на заснеженных ветках. Для сугробов хранить форму поверхности; отдельные частицы моделировать во время падения и осыпания. При снижении теплового запаса сначала уменьшать количество второстепенных частиц и проверять, сохраняется ли отзывчивость жестов. Это гипотезы для замеров. Численные бюджеты согласовать по результатам замеров на разных моделях.
